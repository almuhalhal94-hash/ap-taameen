# ap-taameen
عمل التأمين — المدير المساعد، مدرسة ابن رشد الإعدادي للبنين

موقع ثابت (بدون سيرفر) لتوزيع تأمين حصص المعلمين الغائبين بعدالة، وطباعة كشف التأمين اليومي للتوقيع.

## الملفات
- `index.html` / `style.css` / `app.js` — الموقع.
- `data.js` — الجدول العام للمعلمين (مولّد تلقائيًا، لا تعدّله يدويًا).
- `tools/extract_timetable.py` — يحوّل PDF الجدول العام (تصدير aSc Timetables) إلى `data.js`.
- `assets/` — هيدر الوزارة والخطوط (محلية).

## تحديث الجدول لما يتغيّر
```
pip install pdfplumber
python3 tools/extract_timetable.py الجدول-الجديد.pdf data.js
```
السكربت ينبّه إذا عدد خانات أي معلم ما يطابق «مجموع الحصص».

## قواعد التوزيع
1. ما يدخل التأمين: المعلم الغائب، المفرّغ كليًا، غير المتواجد ذاك اليوم (يوم بلا أي حصة أو اجتماع بالجدول)، أو اللي عنده حصة/اجتماع/مراقبة بنفس الوقت.
2. الترتيب: لا يتجاوز الحد اليومي (افتراضي ١) ← تجنّب ٣ حصص متتالية ← نفس القسم أولًا ← الأقل تأمينًا بالسجل ← الأخف نصابًا اليوم.
3. الحصص الأصعب (مرشحينها أقل) تتوزع أول.

البيانات (السجل والإعدادات) تنحفظ في متصفح الجهاز — خذ نسخة احتياطية من الإعدادات.
