# مصدر فيديو شرح تطبيق التأمين (10 نوفمبر 2026)

- `film.html`: الفيلم كله (جوال three.js + نصوص DOM + خلفية). `window.renderAt(t)` يرسم الثانية t. التعليق يبدأ عند t=2.5 (`O`).
- `rnd.js`: `node rnd.js preview 1 2 3` لقطات في `pv/` · `node rnd.js all 60 <w> <n> 65` فريمات `frames/%05d.jpg` (يرسم الفهارس الزوجية فقط = 30fps). يحتاج Playwright (Chromium + SwiftShader).
- `st/` لقطات التطبيق الحقيقية (cap2.js + seed.js، وضع تجربة)، `mk/` شاشات سفاري/كروم/الكاميرا المرسومة (cap3.js + mock.html)، `rects.js` مواقع العناصر.
- الصوت: `vo_user.wav` تعليق أ. طلال (48k mono، يبدأ عند 2.5 ث في الفيلم)، `vo_words.json` توقيت كل كلمة (whisper، بتوقيت الملف نفسه). `sfx_track.flac` طبقة المؤثرات النهائية جاهزة (65 ث، مخفوضة 4 dB تحت الكلام). `mix.py` يعيد بنائها من `sfx/` و`../../app/snd/`.
- النهائي: فريمات 30fps + (vo مرفوع إلى ~−16 LUFS عند 2.5 ث + sfx) ← loudnorm I=−15 TP=−1.5 ← H.264 crf18 + AAC 192k. نسخة الجوال: 1280×720 crf23.
- كلمة «جوالك» في الصوت: 3.04–3.96 و5.24–5.98 (بتوقيت vo_user.wav) = 5.54–6.46 و7.74–8.48 بتوقيت الفيلم. وفي الشاشة: `#i3` «تكليفاتك كلها في جوالك» و`TT[0]` «بكاميرا جوالك».
